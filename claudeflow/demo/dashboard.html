AI-Augmented BPMN Process Orchestrator

ClaudeFlow connects Claude Sonnet to UiPath Maestro BPMN to create self-healing, intelligently-escalating business process pipelines. Every BPMN stage has a Claude-powered exception handler — no stage fails silently.

BPMN Process Flow

STAGE 1
Intake Validation
Claude classifies contract type, risk tier, jurisdiction, completeness score.
Claude recovers missing fields from raw text; re-scores completeness
STAGE 2
Review Assignment
Risk-aware routing to Legal, Procurement, HR, or CTO Office.
Claude picks backup reviewer if primary unavailable
STAGE 3
Approval Gate
Claude generates reviewer brief. Human-in-loop via UiPath Action Center for high-risk.
Auto-approve for low-risk; escalate for medium/high/critical
STAGE 4
Archive & Notify
Full audit log written. Classification, reviewer, and resolution persisted.
Claude retries or logs failure on archive error

Quick Start

# clone & install
git clone https://github.com/voidd0/claudeflow-uipath
cd claudeflow-uipath
pip install -r requirements.txt

# set credentials
export ANTHROPIC_API_KEY=your_key
export UIPATH_ACCOUNT_NAME=your_account

# run on a contract
python3 -m claudeflow.pipeline contracts/sample_nda.txt

# run tests (no API calls needed)
PYTHONPATH=. pytest claudeflow/tests/ -v
